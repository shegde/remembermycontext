Step 1 of 3

Open a Context Box

Context boxes organize your information by category. Start by opening one of your default boxes.

Step 2 of 3

Add Your Context

Build your context by filling the details from any existing documents or LLM apps. Saving it creates a version and a new version is created every time you save with new information.

Step 3 of 3

Use in Any LLM

Open ChatGPT, Claude or any LLM. Click the extension, select a context box version and insert the text directly or copy paste into your favorite LLM app. That's it!
